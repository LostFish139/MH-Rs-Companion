# 怪物猎人崛起智能狩猎助手

[![Version](https://img.shields.io/badge/version-v2.7.0-blue)](CHANGELOG.md)
[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

一个基于 Python + PySide6 开发的桌面悬浮助手，通过 OCR 实时识别《怪物猎人崛起》任务信息，自动匹配怪物弱点、讨伐建议、白给招式等专业狩猎攻略，以透明聊天气泡形式悬浮于游戏窗口之上。

## 功能特点

### 核心功能
- **实时任务识别**：自动检测游戏窗口，OCR 识别当前承接的任务名称
- **智能怪物匹配**：支持精确匹配、变体字匹配（冰咒龙 ↔ 冰呪龙）、模糊匹配三级匹配机制
- **专业狩猎攻略**：检测到任务后即时展示讨伐建议、白给招式、倒地机制、特殊机制
- **弱点属性查询**：5 种属性弱点等级、弱点部位、状态异常弱点一览
- **武器专属技巧**：根据当前选择的武器，给出针对该怪物的特定操作建议
- **多怪物任务支持**：怪异探究、霸主任务等多目标任务全识别

### 界面特色
- **简洁模式**（默认）：透明悬浮气泡，仅显示核心狩猎信息，不遮挡游戏视野
- **调试模式**：完整展示所有数据，用于校验 OCR 和匹配效果
- **气泡透明度调节**：简洁模式下独立控制气泡背景透明度，文字始终清晰
- **右键菜单切换**：简洁模式下通过右键菜单切换模式、调节设置
- **窗口拖动**：简洁模式下整个窗口区域可拖动定位

## 核心流程

```
游戏窗口检测 → 截取OCR区域 → OCR文字识别 → 三级怪物匹配 → 狩猎攻略展示
```

1. **窗口检测**：每秒检测游戏窗口是否激活
2. **截图优化**：直接截取 OCR 区域，减少 60-80% 处理量
3. **OCR 识别**：RapidOCR 识别任务名称（支持 Tesseract 备选）
4. **三级匹配**：精确匹配 → 变体字归一化匹配 → 模糊匹配
5. **攻略展示**：以聊天气泡形式展示完整狩猎信息

## 安装步骤

### 1. 环境要求

- Python 3.8 或更高版本
- Windows 操作系统
- 《怪物猎人崛起》游戏

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 安装 Tesseract（备选 OCR 引擎）

默认使用 RapidOCR，无需额外安装。如需切换到 Tesseract：

1. 下载 Tesseract OCR: https://github.com/UB-Mannheim/tesseract/wiki
2. 安装后将安装路径添加到系统环境变量 PATH

## 运行说明

### 启动程序

```bash
python main.py
```

或双击 `run.bat` 启动。

程序启动后会显示一个透明悬浮气泡：「系统启动成功！请承接任务，开始狩猎吧！」

### 使用流程

1. 启动程序，透明气泡出现在桌面
2. 启动《怪物猎人崛起》
3. 程序自动检测游戏窗口并开始监控
4. 在游戏中承接任务后，气泡自动显示该怪物的狩猎攻略
5. 切换任务时自动更新信息

### 界面操作

| 操作 | 说明 |
|------|------|
| 拖动窗口 | 简洁模式下拖动任意区域；调试模式下拖动标题栏 |
| 右键菜单 | 切换简洁/调试模式、自动滚动开关、打开设置 |
| 标题栏武器选择 | 选择当前武器，技巧会针对性更新 |
| 设置（⚙️） | 调节透明度、OCR 区域、监控间隔等 |

### 透明度说明

- **简洁模式**：调节的是聊天气泡的背景透明度，文字始终保持清晰可读
- **调试模式**：调节的是整个窗口的透明度

### OCR 测试工具

```bash
python tools/ocr_tester.py
```

提供可视化界面，可实时查看截图、OCR 识别结果和匹配效果。

## 配置说明

核心配置集中在 `config.py`，主要配置项：

```python
# 显示模式：clean=简洁模式（默认），debug=调试模式
UI_CONFIG["default_mode"] = "clean"

# 简洁模式下保留的上下文气泡数
UI_CONFIG["max_context_messages"] = 3

# 气泡背景透明度（0.3-1.0）
UI_CONFIG["bubble_opacity"] = 0.95

# 当前武器（影响技巧展示）
WEAPON_CONFIG["current_weapon"] = "盾斧"

# 技巧显示开关
TIPS_CONFIG["show_general_tips"] = False    # 通用技巧
TIPS_CONFIG["show_weapon_tips"] = False     # 武器通用技巧
TIPS_CONFIG["show_monster_tips"] = True     # 怪物专属技巧（含武器特定技巧）
```

## 注意事项

1. 游戏窗口标题需为「Monster Hunter Rise」，否则无法检测
2. OCR 识别区域需根据游戏分辨率和 UI 布局调整
3. 首次使用 RapidOCR 时会自动下载模型文件
4. 简洁模式下窗口完全透明，可通过欢迎气泡或右键菜单定位
5. 部分怪物（如冰呪龙）的狩猎信息数据可能缺失，仅有弱点数据

## 常见问题

### Q: 程序启动后找不到窗口？

简洁模式下窗口完全透明。程序启动后延迟 500ms 会显示绿色欢迎气泡「系统启动成功！请承接任务，开始狩猎吧！」，可通过该气泡定位窗口位置。也可在桌面右键尝试弹出菜单。

### Q: 检测不到任务？

请确保在游戏中已承接任务，且任务信息显示在屏幕上方区域。如识别区域不准，可在设置中调整 OCR 区域坐标。

### Q: 怪物匹配不上？

系统支持三级匹配（精确 → 变体字 → 模糊），如「冰咒龙」可匹配到数据库中的「冰呪龙」。若仍匹配失败，可能是该怪物不在本地数据库中，可参考 [DATA_GUIDE.md](DATA_GUIDE.md) 补充数据。

### Q: 狩猎信息不完整？

`monster_hunt_info.json` 目前收录 52 只怪物（NGA 数据来源），部分怪物（如冰呪龙）仅有弱点数据而无讨伐建议。可手动补充数据到该文件。
